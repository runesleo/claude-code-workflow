# Repository Instructions

- This repository publishes a sanitized map of Leo's current AI work system: a small shared Core, nine business lines, task continuity, background boundaries, and open-source branches.
- Preserve the real topology and the reasons behind it. Do not flatten the project back into a generic workflow template.
- Keep always-loaded instructions short. Put explanations in docs and load them only when relevant.
- Never add absolute personal paths, live tasks, thread IDs, private state, credentials, accounts, positions, health records, customers, or production controls.
- Public examples may preserve real contracts and business-line names, but their task content and timestamps must be explicitly synthetic.
- Do not make plans, spawn agents, or add workflow artifacts for simple edits.
- `README.md` and default docs are the Chinese source language. `README.en.md` and `*.en.md` files are compatibility mirrors.
- Any behavioral claim must match the files users actually install.
- Run `./scripts/verify.sh` before declaring a change complete.
- Pushes, tags, releases, and public posts require the maintainer's explicit approval.
